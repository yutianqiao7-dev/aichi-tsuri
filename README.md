# 潮どき愛知

愛知県の潮汐・潮回り・マヅメ・天気・風から、いま釣れやすい魚と釣り場、仕掛けとエサがわかるスマホ向け釣りアプリです。

公開ページ: https://yutianqiao7-dev.github.io/aichi-tsuri/

スマホで開いて「ホーム画面に追加」すると、アプリのように使えます。

ひまつぶしアプリ「ウキまち」: https://yutianqiao7-dev.github.io/aichi-tsuri/hima/

## できること

- 県内15の基準港の潮位グラフ、満潮・干潮、潮回り、月齢、日の出・日の入り
- 選んだ時刻の天気・風・波の予報（Open-Meteo）
- 季節・時間帯・潮の動き・天気から出した「釣れやすさ」と、その日の狙い目の時間帯
- 県内34か所の釣り場（釣れる魚、設備、釣り禁止情報、地図リンク）
- 22種の魚のシーズン、仕掛け、エサ、道具、釣り方
- 釣りの待ち時間用のミニアプリ「ウキまち」（ウキ釣りゲーム・魚クイズ・図鑑）

## ファイル

| ファイル | 内容 |
|---|---|
| `src.html` | アプリ本体（編集はここ） |
| `harm.json` | 潮汐の調和定数（tide736.net の推算値から求めたもの） |
| `build.py` | `src.html` と `harm.json` から `docs/index.html` を作る |
| `hima_src.html` | ウキまち本体（魚データは `src.html` から自動で取り込む） |
| `make_icons.py` | アプリアイコンを作る |
| `weather.py` | 天気予報を取って `weather.json` に書き出す（Claude 版のアプリ用） |
| `docs/` | GitHub Pages で公開するファイル |

変更したら次を実行してコミットします。

```bash
python build.py
```

## 注意

釣れやすさは目安です。釣り禁止・立入禁止の場所は変わることがあるので、必ず現地の看板と港のルールに従ってください。

潮汐データ: [tide736.net](https://tide736.net/)（海上保安庁の推算値） / 天気予報: [Open-Meteo](https://open-meteo.com/)
